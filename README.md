# Как рождается самовар

Готовая статическая сборка музейного приложения для GitHub Pages.
Основной формат — сенсорная панель 1080 × 1920; интерфейс адаптируется к другим размерам экрана.

## Состав публикации

- `index.html` — входная страница.
- `assets/` — приложение, стили, шрифты и изображения.
- `.nojekyll` — отключение обработки Jekyll.

Сохранена структура существующего репозитория: публикуется корень ветки `main`.
Для этой структуры в GitHub Pages используется `Deploy from a branch` → `main` → `/ (root)`.
Если ранее был выбран другой источник публикации, настройку нужно проверить отдельно.
Все пути относительные, включая размещение в `/Samovary/`.

Это собранная версия, а не репозиторий исходного React/Vite-проекта.
Следующее обновление выполняется заменой файлов содержимым свежей папки `dist/client` исходного проекта.
Не переносите сюда `node_modules`, локальные журналы, рабочие документы или `dist/server`.

## Локальная версия и редактор

Сборку можно обслуживать локальным HTTP-сервером без внешнего API.
Открытие `index.html` через `file://` не заменяет HTTP-сервер.

Локальный редактор доступен через `?admin=1`.
Его изменения текстов и шрифтов сохраняются только в текущем браузере;
загруженные изображения и видео — в IndexedDB того же браузера.
Они не меняют файлы на GitHub и не переносятся автоматически с localhost на Pages.
Экспорт JSON не является полным пакетом загруженных медиа.

Имя посетителя для игрового клейма существует только в текущем сеансе приложения.
При вводе доступна встроенная экранная клавиатура.
Редактор не является серверной CMS: общей авторизации, базы данных и облачной синхронизации нет.
